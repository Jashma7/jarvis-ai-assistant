# 🤖 Jarvis AI Voice Assistant

A Python-based AI Voice Assistant with voice interaction, GUI dashboard,
system controls, chat history, memory, and local AI integration using Ollama.

## ✨ Features

- 🎤 Voice input using microphone
- 🔊 Voice response using text-to-speech
- 🤖 Local AI responses using Ollama
- 🌐 Google search
- ▶️ Open YouTube
- 🌐 Open Google
- 🧮 Open Calculator
- 🕐 Get current time
- 🖥️ Modern Tkinter GUI dashboard
- 💬 Chat history
- 🧠 Memory management
- ⚙️ Settings management
- 😴 Sleep and wake functionality
- 🛑 Start/Stop assistant

## 🛠️ Technologies Used

- Python 3.13
- Tkinter
- SpeechRecognition
- PyAudio
- Ollama
- Llama 3.2
- PowerShell Speech Synthesis
- Git & GitHub
